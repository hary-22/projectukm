# 📦 Sistem Informasi Inventori Barang

Aplikasi ini dibuat untuk memenuhi tugas proyek Laravel 12 — **membangun sistem manajemen data berbasis web** dengan konsep MVC, autentikasi, dan CRUD yang terstruktur.

---

## 🚀 Fitur Utama
- Autentikasi & otorisasi (Admin & User)
- CRUD Barang & Kategori
- Manajemen User oleh Admin
- Upload Gambar Barang
- Dashboard responsif berbasis Bootstrap
- API JSON sederhana (`/api/barang`, `/api/kategori`)

---

## 🧱 Teknologi
- **Framework:** Laravel 12.x  
- **Bahasa:** PHP 8.3+  
- **Database:** MySQL / MariaDB  
- **Frontend:** Blade + Bootstrap 5  
- **Version Control:** Git / GitHub
